All items in the pending list will be downloaded as an Excel (.xlsx) file (the first column has an ID — do not delete/change this). As soon as they're downloaded, they'll move out of the "Pending" column. After reviewing, write APPROVE or REJECT in English at the end of each row, save the file, and upload it again using "Excel Upload" — each member's account will then be correctly credited (approved) or cancelled immediately.
